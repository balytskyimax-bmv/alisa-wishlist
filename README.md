# 🎂 Вішліст на 1 рочок для Алісоньки ✨

Сучасний, теплий та інтерактивний веб-сайт вішліста для першого дня народження маленької Алісоньки.

## 🌟 Можливості сайту
- **14 обраних товарів** з точними назвами, цінами, категоріями та прямими посиланнями на магазини.
- **По 2 якісні фото на кожен товар**:
  - Інтерактивне перемикання фотографій стрілочками `❮` та `❯` прямо на картці;
  - Індикатори (крапки `1/2`);
  - Клік для збільшення фото (Lightbox).
- **Зручне бронювання в 1 клік**:
  - Гість обирає подарунок і натискає «Зарезервувати цей подарунок»;
  - Вводить ім'я (наприклад: *«Хрещена мама»*, *«Сім'я Ковальчуків»*) та за бажанням тепле побажання;
  - Салют із конфеті при успішному бронюванні 🎉;
  - Статус подарунка моментально стає **«Зарезервовано»** з відображенням імені гостя, що захищає від дублювання подарунків;
  - Можливість легко скасувати бронювання («Це ви бронювали? Скасувати бронь»), якщо плани змінилися.
- **Фільтрація та пошук**:
  - Швидкі фільтри: **Всі (14)**, **✨ Вільні**, **🎁 Зарезервовані**;
  - Фільтр за категоріями (Ляльки та пупси, Розвиваючі іграшки, Спорт та активність тощо);
  - Живий пошук за назвою або приміткою.
- **Адаптивність**: Ідеально відображається на будь-якому смартфоні (iOS / Android) та комп'ютері.

## 🚀 Як запустити локально

Сервер уже запущений і доступний у вашому браузері:
👉 **[http://localhost:8000](http://localhost:8000)**

Якщо потрібно запустити його знову у терміналі:
```bash
cd /Users/mac/.gemini/antigravity/scratch/baby-wishlist
python3 server.py
```
І відкрийте в браузері: `http://localhost:8000`

---

## 📁 Структура проєкту

- `server.py` — автономний легкий бекенд сервер (Python, без сторонніх бібліотек).
- `data/gifts.json` — база даних подарунків (назви, ціни, посилання, примітки, статуси резерву).
- `public/index.html` — святковий інтерфейс сайту.
- `public/styles.css` — стилі, плавні анімації та святкове оформлення.
- `public/app.js` — клієнтська логіка (галерея 2-х фото, фільтрація, модальне вікно, API запити).
- `public/images/` — збережені локальні копії обох фотографій для кожного товару.

## 🌐 Як викласти сайт в інтернет для гостей

Сайт максимально легкий і може бути опублікований безкоштовно за лічені хвилини:
1. **Render.com / Railway.app**: завантажте цю папку в GitHub і підключіть як безкоштовний Web Service (команда запуску: `python3 server.py`).
2. **Vercel / Netlify / GitHub Pages** (якщо використовувати безсерверну базу типу Supabase або Firebase).
3. **Локальний тунель (наприклад, ngrok або Cloudflare Tunnel)**:
   ```bash
   ngrok http 8000
   ```
   Це дасть публічне посилання (наприклад, `https://alisochka-birthday.ngrok-free.app`), яке можна одразу надіслати гостям у Viber або Telegram!
